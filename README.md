# nix-dotfiles

NixOS (flake) + [caelestia shell](https://github.com/caelestia-dots/shell) +
Hyprland. Companion to [`arch-dotfiles`](https://github.com/campbellricing/arch-dotfiles):
the Hyprland config under `hypr/` is a NixOS-adapted subset of that repo's
Lua config (keybinds + core window management for now).

## Layout

| Path | What |
|---|---|
| `flake.nix` / `flake.lock` | flake inputs: nixpkgs (unstable), home-manager, caelestia-shell |
| `configuration.nix` | system config (boot, network, fonts, fcitx5, thunar, hyprland) |
| `hardware-configuration.nix` | generated by the installer — machine specific |
| `home.nix` | Home Manager: caelestia, hyprland wiring, cursor, user packages |
| `hypr/bootstrap.lua` | appended to the HM-generated `hyprland.lua`; `require`s the modules below |
| `hypr/hyprland/*.lua` | keybinds, general, input, misc, animations, decoration, group, gestures |
| `hypr/variables.lua` | apps + keybind definitions (edit this to rebind things) |
| `hypr/scheme/default.lua` | fallback Material palette (caelestia writes `scheme/current.lua` at runtime) |
| `hypr/caelestia/hypr-{vars,user}.lua` | user overrides loaded from `~/.config/caelestia/` |

`hypr/hyprland/`, `hypr/variables.lua` and the `caelestia/hypr-*` files are
symlinked **out of the nix store** into `~/.config`, so editing them here and
running `hyprctl reload` takes effect immediately — no rebuild needed.
`bootstrap.lua`, `*.nix` and package changes need a rebuild.

## Apply changes

```sh
# this repo is a git repo; the flake only sees committed (or at least staged) files
git add -A
sudo nixos-rebuild switch --flake ~/nix-dotfiles#nixos
hyprctl reload            # pick up hypr config changes
```

## Roll back

```sh
sudo nixos-rebuild switch --rollback     # previous generation
# or pick an older generation from the GRUB menu at boot
sudo nix-env -p /nix/var/nix/profiles/system --list-generations   # see what's available
```

## Housekeeping

```sh
sudo nix-collect-garbage -d     # delete all old generations + GC the store
nix-collect-garbage -d          # same for the per-user profile
```

## Not yet ported from arch-dotfiles

`hypr/hyprland/env.lua` (env vars), `execs.lua` (autostart), `rules.lua`
(window rules); the shell fork, SDDM theme, terminal stack (fish/foot/tmux),
nvim, and the full package list. Add them incrementally.
